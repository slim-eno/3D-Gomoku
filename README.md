# 3D 五子棋游戏

一个基于 Three.js 实现的三维五子棋游戏，支持双人对战和人机对战模式。

## 功能特性

- **三维棋盘**：使用 Three.js 渲染的 3D 棋盘，支持旋转、平移和缩放操作
- **多种游戏模式**：
  - 双人对战
  - 人机对战（AI 算法）
- **可定制棋盘**：
  - 多种棋盘大小：5x5x5、7x7x7、9x9x9
  - 多种棋盘皮肤：木质、大理石、金属
  - 多种棋子皮肤：经典、光泽、水晶
- **实时游戏状态**：显示当前玩家、游戏结果
- **胜负判断**：自动检测三维空间中的五子连珠

## 技术栈

- **前端**：HTML5, CSS3, JavaScript
- **3D 渲染**：Three.js (r128)
- **无后端**：纯前端实现，无需服务器

## 快速开始

### 方法一：直接打开

1. 克隆或下载本项目
2. 直接打开 `index.html` 文件即可在浏览器中运行

### 方法二：本地服务器

为了获得最佳体验，建议使用本地服务器运行：

```bash
# 使用 Python 3 启动本地服务器
python -m http.server 8000

# 或使用 Node.js 的 http-server
npx http-server -p 8000
```

然后在浏览器中访问 `http://localhost:8000`

## 游戏操作

### 基本操作
- **放置棋子**：左键点击棋盘格子
- **旋转视角**：右键拖动
- **平移视角**：中键拖动
- **缩放视角**：鼠标滚轮

### 游戏控制
- **游戏模式**：选择双人对战或人机对战
- **棋盘大小**：选择 5x5x5、7x7x7 或 9x9x9
- **棋盘皮肤**：选择木质、大理石或金属风格
- **棋子皮肤**：选择经典、光泽或水晶风格
- **新游戏**：点击"新游戏"按钮开始新游戏

## 核心功能实现

### 1. 三维棋盘渲染
使用 Three.js 创建 3D 网格棋盘，支持不同大小和皮肤。

### 2. 相机控制
实现了流畅的相机操作，包括旋转、平移和缩放。

### 3. 棋子放置
通过射线检测实现鼠标点击棋盘放置棋子的功能。

### 4. 胜负判断
在三维空间中检测所有可能的五子连珠方向（包括平面和空间对角线）。

### 5. AI 算法
实现了简单的 AI 算法，优先防守，然后进攻。
